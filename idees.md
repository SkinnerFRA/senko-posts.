# Idées & styles aimés par Alexis

À lire avant de choisir un sujet. Priorité aux effets dans ces styles.

## Styles qu'Alexis aime
- **Titres et looks stylés** (tape un mot → rendu de pro), plutôt que des outils pratiques.
- Rétro années 80 : chrome biseauté, synthwave, néon, rendu télé vintage / VHS.
- Styles repérés sur MotionElements (catégories) : glitch, high-tech, luxe, pop, grunge.
- Référence : [80s Retro Chrome 5 Titles](https://www.motionelements.com/fr/after-effects-template-21105649-80s-retro-chrome-5-titles) → fait : `ae-chrome-80s`.

## À éviter (refusé par Alexis)
- Diaporama auto, compteur de chiffres, logo reveal avec reflet, interface HUD, texte pop qui rebondit.

## Recherche d'idées
- Sources : https://www.motionelements.com/fr/after-effects-templates et https://www.motionelements.com/fr/premiere-pro-templates
- Les pages produit (`/fr/after-effects-template-...`) s'ouvrent ; les liens `/embed/...` sont bloqués.
- Pour chaque idée retenue : recréer le look sans plugin, tuto manuel en slides + script `.jsx` (After Effects) ou bonus (LUT `.cube`, tuto) pour Premiere Pro.
